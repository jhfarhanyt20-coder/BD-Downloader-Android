**VibeDownloader for Android 1.0.1**

- **Updates install properly:** "Install now" opens your phone's own installer ("Do you want to update this app?"). Tap **Update** and you're done.
- **Always ready:** VibeDownloader keeps running in the background, even after you close it, so shared links and downloads start at once. A quiet notification shows it is running; tap **Stop** there to close it, or turn it off in Settings.
- **Stay up to date:** only the last three versions are supported. A much older app asks you to update before it continues.
